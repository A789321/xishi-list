# 囍事清单 · 备婚工作台

一站式备婚网页应用：**好物共选 + 备婚清单 + 今日计划 + 备婚流程 + 双方准备 + 备忘录 + 预算设置**。
账号登录、内容按账号隔离，管理员可总览所有账号。手机电脑自适应，微信内可用。

## 功能一览

### 账号与权限
- 注册 / 登录（用户名 + 密码），每个账号的数据完全独立、互不可见
- 管理员账号：**阿龙 / 123456**（首次启动自动创建，请在「设置 → 修改密码」里尽快改掉）
- 管理员可切换「全部账号 / 指定账号」视角，查看并管理所有账号的内容
- 旧版本数据自动迁移到管理员账号，不会丢失

### 好物清单（待挑选 / 已购清单）
- 粘贴商品链接或**整段分享文本**（【淘宝】https://c.tb.cn/… 『商品名』点击链接直接打开），自动提取链接、识别平台、带出商品标题
- 点 ♥ 投票，家人实时可见；一键跳转淘宝 / 天猫 / 京东 / 拼多多 / 抖音下单
- **已购清单独立界面**：下单后「标记已下单」，商品移入已购清单（记录下单人、下单时间、已购合计），避免重复购买；可随时移回待挑选
- 首页卡片**一键删除**（7 秒内可撤销）、批量标记 / 删除、一键清空全部（可撤销）
- 搜索、阶段 / 分类 / 平台 / 账号筛选、最新 / 热度 / 价格排序

### 备婚清单
- 分类勾选清单（婚礼现场用品 / 仪式道具 / 喜糖喜帖 / 宾客伴手礼…），逐项确认不遗漏
- 自定义分类、添加 / 修改 / 删除事项，完成进度实时统计

### 今日计划
- 按日期添加待办，今天 / 全部 / 未完成视图，过期提醒，勾选完成

### 备婚流程
- 婚礼倒计时（设置婚期后自动显示）
- 时间线节点：提亲、订婚、领证、拍婚纱照…自定义日期与备注，逐项标记完成

### 双方准备（男方 / 女方）
- 服饰清单（新郎西装 / 新娘婚纱等，勾选备齐）
- 宾客名单（姓名、人数、关系、电话、备注，自动统计人数，电话可直接拨打）
- 车队安排、彩礼 / 嫁妆、伴手礼等字段，填写即自动保存

### 备忘录
- 商家联系方式（婚庆 / 酒店 / 摄影师，点击拨号）
- 宾客忌口、婚礼灵感收集、家庭沟通，输入自动保存

### 设置
- 婚期、婚礼地点、总预算、已花费（含预算进度条与已购合计参考）
- 三套风格一键切换：朱砂囍韵（红金新中式）/ 桃夭粉黛 / 青黛雅集
- 修改密码、数据导出 / 导入备份、清空示例 / 一键清空

## 一、本地运行（30 秒）

安装 Node.js 16+（推荐 18/20），**零依赖，无需 npm install**：

```bash
node server.js
```

打开 http://localhost:3000 ，用管理员账号 **阿龙 / 123456** 登录，或注册新账号。
数据保存在 `data/db.json`（密码加盐哈希存储）。

## 二、免费部署到公网（Render，约 5 分钟）

1. 把本工程所有文件上传到 GitHub 仓库（网页拖拽上传即可）。
2. render.com 用 GitHub 登录 → `New +` → `Blueprint` → 选仓库 → `Apply`（自动读取 render.yaml，免费无需信用卡）。
   - 手动方式：`New +` → `Web Service` → Runtime 选 Node，Build Command 留空，Start Command 填 `node server.js`，Instance Type 选 Free。
3. 1~2 分钟后得到 `https://xxx.onrender.com` 公网链接，发给家人，各自注册账号即可。

> 免费实例 15 分钟无访问会休眠（再打开约 30 秒唤醒）；重新部署时磁盘数据可能重置，请定期在应用内「导出备份」，需要时用「导入备份」恢复。长期稳定使用建议升级付费实例挂载磁盘，或部署到自有服务器 / NAS。

备选：Railway / Glitch 导入仓库，启动命令 `node server.js`；或自有电脑 + cpolar / natapp 内网穿透。

## 三、使用指南

1. **注册账号**：打开网址 → 「没有账号？注册一个」→ 设置用户名密码。每人一个账号，内容互不可见。
2. **添加好物**：好物清单 → 添加好物 → 粘贴链接或整段分享文本 → 保存。
3. **家人共选**：各自登录后只能看到自己的清单；如需全家共选一份，可共用一个账号，或由管理员统一查看。
4. **避免重复购买**：下单后点「标记已下单」→ 商品进入「已购清单」，待挑选里不再显示。
5. **管理员**：阿龙登录后顶栏出现账号视角切换，可查看全部账号或指定账号的好物与各模块内容；「设置 → 账号总览」可看每个账号的统计。
6. **备婚各模块**：顶部导航切换；备婚清单逐项勾选；流程里设置婚期后看倒计时；双方准备里登记宾客与车队彩礼；备忘录随手记。

## 四、常见问题

- **微信里跳转不了购物 App？** 点右上角「···」→「在浏览器打开」。
- **淘口令能用吗？** 纯淘口令符号不行；请在淘宝分享时选「复制链接」，整段文字直接粘贴即可。
- **忘记密码？** 目前无自助找回（家庭内部应用），可请管理员在数据库 `data/db.json` 中删除该用户后重新注册；管理员密码可在应用内修改。
- **数据安全吗？** 密码加盐哈希存储；账号间内容隔离。链接知道即可访问登录页，请勿公开传播管理员密码，部署后第一件事就是修改默认密码。

## 五、技术说明

- 后端：原生 Node.js（http / fs / crypto），零第三方依赖；JSON 文件原子写入；scrypt 密码哈希；Token 会话；SSE 实时广播（断线降级轮询）。
- 前端：原生 HTML / CSS / JavaScript，无框架无 CDN。
- 主要接口：`/api/register` `/api/login` `/api/logout` `/api/password` `/api/state?as=` `/api/settings` `/api/data` `/api/items`(CRUD/投票/清空) `/api/seed` `/api/export` `/api/import` `/api/events`(SSE)。
- 环境变量：`PORT`（默认 3000）、`DATA_DIR`（默认 ./data）。
